# 个人微信渠道

历史设计记录：接入个人微信渠道。

共同保持两个 MCP 工具与本机 HTTP 问答入口。队列、租约、账号绑定、去重和消息关联按渠道隔离；平台错误不输出凭据，结果未知不盲目重发。

## 个人微信

- 腾讯公开 ClawBot/iLink HTTP 协议；扫码登录助手与长轮询收消息，不安装或启动另一个 Agent。
- 绑定扫码用户、Bot ID，持久化游标与会话上下文。缺少 context_token 时排队等待用户先发消息；令牌失效停止发送，不伪装成功。
- 第一版仅 /reply 问题编号 回答，不猜测无关联文字。不会宣称支持普通微信好友群或无限期主动通知。
- 登录凭据仅保存被忽略的本地文件，不进入插件 manifest、日志或 Git；扫码及真实账号限制待用户实测。

每阶段完成后运行旧渠道回归与新增渠道测试，再扫描公开内容、提交、推送指定 SHA 并核验远端 ref。

## 实现状态

- 微信 0.5.0：扫码、文本问答、持久化与异常处理已实现，42 项检查与隔离插件加载验证见 [验收记录](../validation.md)。
- 外部渠道的真实手机联调由用户配置账号后逐一完成，入口见 [测试说明](../channel-testing.md)。
